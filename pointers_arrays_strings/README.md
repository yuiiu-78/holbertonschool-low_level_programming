# C - Pointers, Arrays and Strings

## Description
This project introduces pointers, arrays, and strings in the C programming language.

## Task 0: 98 Battery st.

The function reset_to_98 takes a pointer to an integer and updates the value stored at the pointed memory location to 98.

## Function Prototype

void reset_to_98(int *n);

## Compilation

gcc -Wall -Werror -Wextra -pedantic -std=gnu89

## Concepts
- Pointers
- Memory addresses
- Dereferencing pointers
- Modifying variables through pointers
