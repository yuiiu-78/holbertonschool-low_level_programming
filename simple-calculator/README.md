# Simple Calculator

## Compilation

gcc -Wall -Werror -Wextra -pedantic -std=gnu89 calculator.c -o calculator

## Run Instructions

Run the program using:

./calculator

## Supported Operations

The initial version displays a menu with options for:
- Addition
- Subtraction
- Multiplication
- Division
- Quit (0)

Only the menu display and quit option are implemented in Task 0.

## Numeric Behavior

The menu choice is read as an integer using scanf.

## Known Limitations

Arithmetic operations are not implemented in this initial version.
